About QuickNotes

QuickNotes is used to write short notes or mark-ups one does while reading not in a book but in a web page

How to use QuickNotes

  1. Open QuickNotes Home page.
  2. Type your idea into the note box.
  3. Save the note for later.

Features

  • Fast
  • Works in your browser
  • Simple,clean interface
